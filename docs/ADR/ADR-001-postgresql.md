# ADR-001

## Title

Use PostgreSQL as the primary relational database.

## Status

Accepted

## Context

The project requires a modern relational database widely used in European companies.

## Decision

PostgreSQL will be used.

## Reason

- Open Source
- Docker Friendly
- Popular in SaaS
- Excellent EF Core support

## Consequences

The project will target PostgreSQL only in version 1.
